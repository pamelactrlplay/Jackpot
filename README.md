# Mini Jackpot

Um jogo de caça-níqueis (Jackpot) simples, divertido e totalmente desenvolvido com **HTML5**, **CSS3** e **JavaScript puro (Vanilla JS)**. Desenvolvido para praticar manipulação de DOM, lógica de intervalos (`setInterval`) e estilização moderna.

## Demonstração das Funcionalidades

* **Sorteio Animado:** Efeito de rolagem de números simulando uma máquina caça-níqueis real.
* **Validação de Vitória:** Verifica se os três números sorteados são idênticos para premiar o jogador.
* **Interface Responsiva:** Estilização centralizada com sombras e efeitos de transição nos botões.

## Tecnologias Utilizadas

* **HTML5** para a estrutura da página.
* **CSS3** para o layout, flexbox, fontes e efeitos visuais.
* **JavaScript** para a lógica do jogo, manipulação do DOM e controle de eventos.

## Como Executar o Projeto

Siga os passos abaixo:

1. Abra a pasta do projeto via terminal. Use o comando _node server.js_ para rodar o projeto
